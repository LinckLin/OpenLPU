## 2. 决策

**主方向 = A（免训练投机解码），实测门槛 α≥0.4 立项；副轨道 = B（INT4 KV + QK-norm 折叠，
含专用旋转器条件）并行；C 受限低成本验证后归档；D/E 留 gen-2/常规队列。**

### 理由（逐条可审计）

1. A 是唯一在 D13 约束内打破权重墙（B1）的方向（阵列利用率 3.66%；一切 KV/写口优化收敛到
   权重流渐近线 1207.9）。投机验证步 = 批解码（n 候选共享一次权重流 + 一次 KV 窗口读）。
2. 文献对小模型正面证据：Lookahead 明确"smaller models exhibit higher speedup"（1.5–2.3×）；
   REST（2.16–2.36×）/LLMA（≈2×）检索/匹配草案零训练；**EAGLE 负证据（7B 无可用 draft、
   13B 有 draft 无增益、33B 1.12×/70B 1.88×）针对经典 draft-模型路径在小目标关闭**——
   与我们选定的 host 侧 n-gram/Lookup 草案正交。
3. 架构适配：链式验证（n 候选因果平移）用既有 BMM batch≤16 表达，无需树掩码；KV staging
   提升到候选循环外 + lm_head 权重流跨候选共享，均 runtime/调度层 + ISA 最小增量。
4. 不冒险：先测后建（α≥0.4 立项；α∈[0.25,0.4) 降 gen-2；α<0.25 关闭）。
5. B 与 A 相乘且低风险：INT4 KV 减少验证步共享 KV 读；折叠免校准；文献与 O2 实测互证；
   即使 A 不达标，B 独立成立。
6. C 诚实降级：≤2 周受限验证（GPTQ g64/128 + SpinQuant-nohad 编译期吸收；门槛 ≥8/10 或
   ΔPPL≤2%），不过即归档 W4A16 backlog（D5 INT4 数据通路已达成、部署质量如实记录不变）。

## 3. 执行计划（审计一致后）

1. **A 立项前置（实测门槛）**：qrun 实现 host 侧 n-gram/Lookup 草案 + 链式批验证模拟，
   测 0.6B 贪心 α（HellaSwag/通用文本）；α≥0.4 → 立项，否则报告降级。
2. **B 数值验证 + 条件项**：QK-norm 折叠（**带符号 scale_c = k_norm[c]×s_q；实测 0.6B
   有 3.4% 负通道（min −3.86），dequant 用带符号 BF16 scale 乘；4B/8B 放量时重检**）+
   INT4 KV（K per-channel 静态 pre-RoPE / V per-token）在 ref/qrun 层测 ΔPPL 与交叉一致；
   **on-read RoPE 代价入模型**：pre-RoPE 存储把 RoPE 从 APPEND 一次（~48 cyc/token）变为
   每次窗口读在线旋转（2048 slots × 8 heads × 128 dims ≈ 2.1M 元素/层/步；现有 Vector
   引擎 ≈131K cyc/层 ≈ 4× 绑定值）→ **条件项 = 专用旋转器微硬件（矩阵引擎旁路，
   ≈128 cyc/层）**；1.27× 天花板仅在该条件成立时有效，报告中必须同列"无旋转器"口径。
3. **C 受限验证**：GPTQ g64/128 + 编译期吸收；判据 ≥8/10 或 ΔPPL≤2%；不过 → 归档（记录
   含 W4A8KV16 配置注与 ctx 限定）。
4. D/E 维持 roadmap 排队。

## 6. B' 交付裁决（2026-08-17，sram-macro 合成化重构后更新）

**B' 全链路落地完成**：数据通路（APPEND 侧 INT8-K 折叠/INT4-V 量化 + B-feed 流式
dequant+on-the-fly RoPE，无 staged 写、无新指令）+ 三端参考 ≤1 ULP（co-sim 3/3、
默认回归 24/24、qsim 52）+ 修正时序模型复现 **1049.3（1.212×）主口径**。执行中抓出并
修复 1 个阻塞 bug（kv_bfeed row_valid 握手粘性 → B[k]=B[k−1] 偏斜）与 3 处 executor
CD 重构回归。**口径修正（round-1 评审）**：原「Vector 引擎 ≈131K cyc/层」按 ROPE 延迟
串行计，有误——流水吞吐 = 1 向量/cyc → 计算 16.4K cyc 可隐藏，真正瓶颈 = 指令发射
带宽与 SRAM 写口（256 B/cyc）；B-feed 流式融合（无 staged BF16 写）是 1049.3 唯一可达
架构。
**DC 存储墙收尾（sram-macro 重构）**：`khat[0:16383]` 平面数组 → `kh4096x64` SMIC28
SRAM 宏（4096×64，每 64b 字 4 entry×16b bf16，地址 `{ch[6:0], n[6:2]}`），`knorm`→
`kn128x16` RF 宏，K 行生产串行化（每周期 1×64b 读；DC(N=4) 2 读/行、PF(N=128) 64 读/行，
旋转锥每周期 4 token），写路径 (b)（n-组内层 + s_q 128×2B 全量寄存 + 尾组零填充）。
宏 `.lib`（SMIC28 0.9V/28nm）→ `.db` 转库后与 sky130 逻辑（1.8V/130nm）并列读入 DC——
**此混搭 ≠ 流片口径**，仅作「khat 墙消除后控制平面逻辑 Fmax 可达性评估」。结果：**存储墙已破
（内存 40.7→5.2 GB、无 256 读口爆炸）、compile_ultra 跑通、tt Fmax ≈ 14.7 MHz**——关键路径
在逻辑侧 `rope_sincos` 组合锥（68.11 ns，宏不参与），证实阶段 2 `ang4096x64` 角度缓存是
消除该锥的直接降路径。co-sim 3/3 0 ULP、回归 24/24、qsim 52、lint/build 过。

## 7. 阶段 2 降路径裁决更新（2026-08-17，round-2 评审一致后撤销）

**撤销 §6 的「阶段 2 `ang4096x64` 角度缓存是消除该锥的直接降路径」**。round-2 对
`plans/fmax-pipeline-plan.md`（锥流水化）与 `plans/smic28-rebaseline-plan.md`（SMIC28
全流程重立）两份计划评审一致，据此更新主降路径：

- **角度缓存否决（如实推演）**：`ang4096x64`（4096 字×64b=32 KB）仅容 128 位置
  （每位置 64 对 cos/sin bf16=256 B）；滑动窗口 R=2052 位置全量缓存需 2052×256 B=
  525 KB≈4.2 Mbit→28nm 约 1.7–2.8 mm²（按 1.5–2.5 Mbit/mm²），远超 28nm 控制平面
  逻辑面积；128 位置滑动缓存每 decode 步失效 2052−128=1924 次重算→每层
  1924×64≈123K 次 rope_sincos，远超 HBM 预算 26,317 cyc 容纳能力，回到原墙。
  故角度缓存**不为主降路径**；`ang4096x64` 宏保留备用（未来小窗/短序列）。
- **主路径 = 行生产锥 register-slice 流水化**：把 kv_bfeed K 行生产组合锥（68.11 ns，
  全锥 ≈28–31 顺序 op 级）切成 ~10–12 级流水、每级 ~2–3 op（含 rope_sincos 内部
  op 级切分：Cody-Waite 归约后、LUT 取表后、Hermite 每乘加对之间）；op 次序与舍入
  次序不变 → co-sim 仍 0 ULP。详见 `plans/fmax-pipeline-plan.md`。
- **工艺口径**：14.7 MHz 仅作 sky130 历史参考值；验收锚定 SMIC28 新基线（D18）的
  pre-pipeline Fmax 为「前值」、流水化后 28nm Fmax 为「后值」。
